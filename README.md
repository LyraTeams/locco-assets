# locco-assets

Public brand assets for Locco. Files here are served from a public URL for services that
fetch images themselves (Google Wallet `programLogo`).

| File | Use |
| --- | --- |
| `google/program-logo-660.png` | Google Wallet program logo, 660×660, padded for the circular crop |

Source SVGs and the other generated sizes live in the main repository under `assets/brand/`.
